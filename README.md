# ⌨️ Ky- — Physical-Key Keyboard for Android

> An Android keyboard project aimed at devices with physical keys and limited touch input.

[![Android](https://img.shields.io/badge/Platform-Android-3DDC84?logo=android&logoColor=white)](https://developer.android.com/) [![Project](https://img.shields.io/badge/Type-Personal%20Project-6E56CF)](https://github.com/generativimt12)

## 🎯 Goal

Ky- explores a **real hardware-keyboard experience on Android**, with the physical keypad acting as the user's normal text input method.

A central design requirement is to work as a keyboard rather than depend on an Accessibility Service, making the project relevant to Android devices where Accessibility access is unavailable or restricted.

## 🧭 Focus

- ⌨️ Physical-key input
- 📱 Android keyboard architecture
- 🔧 Compatibility with unusual / hybrid devices
- ♿ Avoiding unnecessary Accessibility dependencies
